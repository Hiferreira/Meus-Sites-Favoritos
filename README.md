
# Meus Sites Favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática do curso Técnico em Desenvolvimento de Sistemas.

O objetivo é criar uma página web para reunir cinco sites favoritos, utilizando conceitos básicos de HTML e CSS.

## Sites selecionados

1. **YouTube** - Vídeos, entretenimento e aprendizado.
2. **Investidor10** - Informações sobre investimentos.
3. **Duolingo** - Aprendizado de idiomas.
4. **Chess.com** - Jogos de xadrez online.
5. **Cambridge English** - Atividades para praticar inglês.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Exibição dos cinco sites favoritos.
- Imagens representando cada site.
- Links para acessar os sites.
- Organização dos elementos na página.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pelos links dos seus sites favoritos.
